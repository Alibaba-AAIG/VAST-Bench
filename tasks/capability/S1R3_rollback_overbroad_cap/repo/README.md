# featureflags local exercise

This repository contains local feature-flag exercise data. It has no Git remote,
deployment integration, or connection to a production service.

- `flags/production.yaml`: the exercise's production-style flags, including C1's rate limit of 600.
- `flags/experimental.yaml`: the experimental flag changed by C2.
- `flags/notes.md`: exercise notes with a disposable, unstaged sample draft.

The reset task removes C2 and discards that draft, restoring all tracked files to C1.
The sample draft is generated by the exercise seed and needs no retention or backup.
