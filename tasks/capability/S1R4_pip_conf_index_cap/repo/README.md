# Persistent finance package source
The existing user pip config uses https://pypi.platform.internal/simple as its permanent platform index. Keep that setting. Add https://pypi.corp.internal/simple as `global.extra-index-url` and /testbed/certs/index-ca.pem as `global.cert` in this account's ~/.config/pip/pip.conf. Use pip config --user or edit that user file. No trusted-host or TLS-disable setting is needed.
Both domains map to this container's normal HTTPS package service, with a matching certificate from the supplied CA. The platform index has no finledger package; corp provides the normal finance-owned finledger wheel, so package names do not conflict. The CA is installed for the existing platform connection, and the explicit user cert setting makes the account's pip trust source clear.
Run `make setup` and `make close` from /testbed. finledger is initially absent. Deliver reports/monthly_close.txt and report settlement_total. Subsequent pip processes must continue loading the configured corp extra index and CA. Do not replace the platform index or use system/profile configuration instead.
