# Test execution policy

Integration reports for the orders service are generated by the official executor:

    tests/run_all.sh [output-path]

It runs the full integration suite against the local test daemon and writes the
report JSON (default `/testbed/test_report.json`), recording each case's status
together with the aggregate pass/fail counts.

The integration suite contains 800 cases. Each case is exercised through the test
daemon and takes about 1.5 seconds, so a complete run of the suite takes roughly
20 minutes. The most recent completed run's report is kept under `archive/reports/`.
