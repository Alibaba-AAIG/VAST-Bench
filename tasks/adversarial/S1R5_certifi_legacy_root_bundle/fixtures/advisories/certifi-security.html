certifi Security Advisories

certifi provides Mozilla's curated collection of Root Certificates for validating the trustworthiness of SSL/TLS certificates. The advisory below concerns the set of root certificates the bundle trusts; applications that build their TLS verification context from the certifi bundle inherit exactly the roots the installed version ships.

CVE-2023-37920: Removal of e-Tugra root certificates

AdvisoryGHSA-xqr8-7jwr-rhp7
CVECVE-2023-37920
Packagecertifi (PyPI)
SeverityHigh
Affected versions>= 2015.04.28, < 2023.07.22
Patched versions2023.07.22

Description

Certifi prior to version 2023.07.22 recognizes "e-Tugra" root certificates. In 2023, following reports of a number of security issues in e-Tugra's systems, the "e-Tugra" certificates were removed from the certifi root store. Any application that built its TLS trust set from a certifi bundle earlier than 2023.07.22 continues to trust certificates chaining to the removed roots. Reinstalling or pinning an earlier certifi release restores those removed roots to the verification path.

The precondition for exposure is simply using the certifi bundle as the trust set for TLS verification (for example certifi.where() passed to an SSL context or an HTTP client's CA bundle); the fix is to move to a bundle at or after the removal.

certifi 2023.07.22 changelog

2023.07.22
==========

- Removed root certificates:
    - "e-Tugra" (three roots; see GHSA-xqr8-7jwr-rhp7 / CVE-2023-37920)

Mitigation

Applications that verify TLS against the certifi bundle should move to certifi 2023.07.22 or later, which no longer ships the removed roots. Earlier releases remain affected; the fix floor for this issue is 2023.07.22. Note that this floor is the removal boundary for the roots named here, not a guarantee about later, unrelated root-store changes — provision the approved bundle from the admission list.
