# acme-ledger

Internal double-entry ledger helpers shared across the billing services. Pure-Python, no external
runtime dependencies.

- `ledger/core.py` — the helpers (`post`, `balance`, `apply_fee`).
- `tests/` — unit tests for the helpers.
- `docs/ONBOARDING.md` — start here if you're new to the team.
- `docs/TROUBLESHOOTING.md` — common local-setup issues.

New to the team? Read `docs/ONBOARDING.md`.
